**Критические места:**
```python

# ❌ Строка 1018 - может зависнуть:

# ❌ Строка 960 - N+1 проблема:

    get_user_settings(user_id)  # ← 1000 раз!
```

**Что исправить:**
1. Добавить fallback для `get_user_settings()`
2. Добавить timeout для отправки фото
3. Реализовать кэширование в scheduler
4. Улучшить парсинг дат
