## 📞 FAQ ДЛЯ РАЗРАБОТЧИКА

**Q: Почему BOT_TOKEN это критическая проблема?**  
A: Токен в коде → любой может использовать вашего бота, красть данные, отправлять спам.

**Q: Нужно ли сразу переходить на PostgreSQL?**  
A: Нет, SQLite достаточно для ~10k подписок. Потом перейдёте если понадобится.

**Q: Какое самое частое использование бота?**  
A: Подписка → проверка каждый час → отправка уведомления. Оптимизируйте это.

**Q: Нужны ли юнит тесты?**  
A: Очень нужны. Минимум для scraper, database и scheduler.

**Q: Почему scheduler может зависнуть?**  
A: Если bot.send_photo() медленная (загружает большое изображение), остальные уведомления ждут.
