# 🚀 БЫСТРЫЙ СТАРТ - 3 ШАГА

## Шаг 1: Проверить готовность

Откройте PowerShell/CMD в папке проекта и выполните:

```powershell
python check_bot_ready.py
```

Должно появиться:
```
✅ Результат: 6/6 проверок пройдено
✅ ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ!
```

## Шаг 2: Убедиться что .env файл есть

Проверьте что файл `.env` содержит:
```
BOT_TOKEN=your_token_here_from_botfather
```

## Шаг 3: Запустить бота

Выполните одну из команд:

### Способ А - PowerShell (рекомендуется для Windows)
```powershell
.\start_bot.ps1
```

### Способ Б - Батник (двойной клик)
```
Дважды кликните на: start_bot.bat
```

### Способ В - Прямой запуск
```powershell
python bot.py
```

## ❌ Если что-то не работает

### Ошибка: "BOT_TOKEN не установлен"
1. Откройте файл `.env`
2. Проверьте что BOT_TOKEN скопирован полностью
3. Сохраните файл
4. Попробуйте снова: `python check_bot_ready.py`

### Ошибка: "Module not found"
1. Переустановите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
2. Попробуйте запустить бота снова

### Бот запускается но вешает
1. Проверьте интернет соединение
2. Убедитесь что BOT_TOKEN корректен
3. Попробуйте перезагрузить компьютер
