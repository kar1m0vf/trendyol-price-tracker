## 🎯 Что делает бот?

✅ Отслеживает цены товаров на Trendyol
✅ Проверяет цены каждые 60 минут  
✅ Отправляет уведомления об изменении цен
✅ Ведет историю цен в SQLite БД
✅ Поддерживает 4 языка (RU, EN, AZ, TR)
✅ Защита от спама через middleware

## 🚀 Команды бота

```
/start              Начало работы
/subscribe <URL>    Подписаться на товар
/unsubscribe        Отписаться
/trending           Трендовые товары
/history            История цен
/settings           Мои настройки
```

## ❓ Если что-то не работает

1. Проверьте готовность:
   ```bash
   python check_bot_ready.py
   ```

2. Убедитесь что .env содержит BOT_TOKEN

3. Переустановите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Прочитайте [STATUS_REPORT.md](../reports/STATUS_REPORT.md)
