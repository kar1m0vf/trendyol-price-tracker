### 1. **Целевая цена (Price Alert)** ✅
Новая функция для уведомлений когда цена товара упадет ниже указанного значения.

**Команда:**
```
/price_alert <ID подписки> <Целевая цена>
```

**Пример:**
```
/price_alert 5 2500
```

**Работает так:**
- Устанавливаете целевую цену на товар
- Бот отслеживает цену и отправляет уведомление когда она упадет ниже целевой
- После уведомления целевая цена автоматически очищается

**Описание в коде:**
- `database.py` - Добавлено поле `price_alert` в таблицу `subscriptions`
- `bot.py` - Команда `/price_alert` для установки целевой цены
- `check_all()` - Проверка price_alert в функции уведомлений (приоритет выше других условий)

---

### 2. **Улучшение логики уведомлений** ✅
Добавлена иерархия проверок для более интеллектуального уведомления:

1. **Price Alert** - Если цена <= целевая - уведомление (приоритет 1️⃣)
2. **Hourly Mode** - Если включен режим "Каждый час" - уведомление (приоритет 2️⃣)
3. **Discount Mode** - Если включен режим "На скидку":
   - Проверка % скидки
   - Проверка min/max цены
   - Уведомление только на скидку

**Это означает:**
- Если установлена целевая цена - другие правила игнорируются
- Уведомления становятся более полезными и релевантными
