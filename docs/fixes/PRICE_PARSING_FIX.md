# Исправление парсинга цен

## Проблема
Бот не мог получить актуальную цену для многих продуктов Trendyol, показывал "цена не найдена" и только название товара.

## Причины
1. **Cloudflare защита**: Trendyol использует Cloudflare, который блокирует обычные запросы `requests`
2. **Устаревшие селекторы**: Trendyol изменил структуру HTML и классы CSS
3. **Недостаточный поиск**: Не использовались все доступные источники данных о цене

## Исправления

### 1. Использование cloudscraper по умолчанию
**Было**: `requests.get()` использовался первым, `cloudscraper` только как fallback
**Стало**: `cloudscraper` используется по умолчанию, если доступен (обходит Cloudflare)

### 2. Добавлен поиск в JavaScript переменных
**Новое**: Поиск цены в `window.__PRODUCT_DETAIL_APP_INITIAL_STATE__` и подобных переменных
- Это самый надежный источник данных о товаре
- Trendyol хранит всю информацию о товаре в этих переменных

### 3. Расширен список CSS селекторов
**Добавлены селекторы**:
- `span.pr-new-br` - новая цена
- `[data-testid*="price"]` - data-атрибуты
- `div.product-price-container span` - контейнеры цен
- И другие современные селекторы

### 4. Улучшен поиск в JSON-LD
- Более глубокий рекурсивный поиск цены в структурах JSON-LD
- Поддержка различных форматов данных о цене

### 5. Улучшен парсинг JavaScript переменных
- Поддержка различных форматов объявления переменных (`var`, `let`, `const`)
- Лучшая обработка JSON с комментариями и trailing commas
- Более надежный парсинг вложенных структур

### 6. Добавлен поиск в data-атрибутах
- Поиск цены в `data-price` атрибутах элементов

### 7. Улучшено логирование
- Добавлено логирование успешных извлечений цены
- Логирование предупреждений при неудаче

## Порядок поиска цены (новый)

1. **JavaScript переменные** (`window.__PRODUCT_DETAIL_APP_INITIAL_STATE__` и др.)
2. **Meta теги** (`product:price:amount`)
3. **JSON-LD** (структурированные данные)
4. **CSS селекторы** (расширенный список)
5. **Регулярные выражения** (поиск "число TL" в тексте)
6. **Data-атрибуты** (`data-price`)

## Результат

Теперь бот должен успешно получать цены для большинства товаров Trendyol, используя множественные методы извлечения данных.

## Тестирование

Для проверки работы:
1. Подпишитесь на несколько товаров Trendyol
2. Проверьте, что цены отображаются корректно
3. Проверьте историю цен командой `/history <id>`

Если проблема сохраняется для конкретных товаров, проверьте логи в `scraper.log` для диагностики.
