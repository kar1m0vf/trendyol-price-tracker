# Улучшение команды "Мои подписки"

## Проблема
Бот отправлял каждую подписку отдельным сообщением, что спамило чат пользователя.

## Решение
Теперь все подписки отображаются в одном сообщении с кнопками для редактирования каждой подписки.

## Изменения

### 1. Команда `/mysubs` (или кнопка "Мои подписки")
**Было**: Каждая подписка отправлялась отдельным сообщением
**Стало**: Все подписки в одном сообщении

### 2. Формат отображения подписок
Для каждой подписки показывается:
- ✅ **Статус** (Активна/Неактивна) - определяется наличием цены
- **ID** подписки
- **Название товара** (или URL, если название недоступно)
- **Текущая цена** (или "цена неизвестна")
- **Режим уведомлений** (Каждый час / Только при скидке)
- **Целевая цена** (если установлена)

### 3. Кнопки редактирования
Под каждой подпиской в списке есть кнопка:
- `⚙️ Редактировать ID X` - открывает меню редактирования подписки

### 4. Меню редактирования
При нажатии на кнопку редактирования пользователь получает:
- Детальную информацию о подписке
- Клавиатуру с опциями:
  - Смена режима уведомлений (Каждый час / Только при скидке)
  - Просмотр истории цен
  - Отписка

## Пример отображения

```
📋 *Ваши подписки:*

✅ *Активна* | ID: `1`
📦 Название товара
💰 2500 TL | Каждый час
🎯 Целевая цена: 2000 TL

⚠️ *Неактивна* | ID: `2`
📦 Другой товар
💰 цена неизвестна | Только при скидке

[⚙️ Редактировать ID 1]
[⚙️ Редактировать ID 2]
```

## Новые ключи локализации

Добавлены ключи для всех языков (ru, en, az, tr):
- `mysubs_header` - заголовок списка подписок
- `status_active` - статус "Активна"
- `status_inactive` - статус "Неактивна"
- `mode_hourly` - режим "Каждый час"
- `mode_discount` - режим "Только при скидке"
- `btn_edit` - кнопка "Редактировать"
- `edit_subscription` - заголовок "Редактирование подписки"
- `price_alert_label` - метка "Целевая цена"
- `minutes` - "минут"
- `notify_percent` - "Процент уведомления"
- `interval` - "Интервал"

## Технические детали

### Callback handler
Добавлен новый обработчик `edit_sub:` в `callback_handler()`:
- Проверяет права доступа пользователя
- Формирует детальную информацию о подписке
- Отправляет сообщение с меню редактирования

### Обработка ошибок
- Fallback для старых подписок (без `price_alert`)
- Обработка ошибок Markdown форматирования
- Логирование ошибок

## Результат

✅ Пользователи получают все подписки в одном сообщении
✅ Удобный доступ к редактированию каждой подписки
✅ Чистый чат без спама
✅ Полная локализация на 4 языка
